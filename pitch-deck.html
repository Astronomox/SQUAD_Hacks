Squad API Integration

Squad is the verification infrastructure

Not a superficial integration. Squad APIs are the core transactional layer — funds cannot be disbursed without passing AI verification.

🔐 Powered by Squad API
  • POST /virtual-account — Payroll escrow vault. Funds locked until AI clears each employee.
  • POST /payout/transfer — Bulk salary disbursement to verified employees only.
  • GET /transaction/verify/:ref — Transaction confirmation for immutable audit trail.
  • POST /virtual-account/simulate/payment — Sandbox testing of escrow flow.
5 / 10
AI / Data Intelligence

Real machine learning — not rules

Isolation Forest model trained on payroll behavioural signals. Identifies ghost workers that manual review misses by detecting collectively suspicious patterns.

Isolation Forest

200 estimators, 8% contamination rate. Scores each employee 0–100 risk.

Feature Engineering

6 signals: enrollment hour, batch size, IP sharing, device reuse, salary ratio, attendance gap.

Facial Liveness

3-step verification: face detection → blink detection → identity match. Blocks photo/video spoofing.

Graph Analysis

Identifies coordinated fraud networks — employees linked by shared IP, device, or batch enrollment.
